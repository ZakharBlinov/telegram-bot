# 🤖 SpotChat — Telegram бот для поиска событий и знакомств

**SpotChat** — это многофункциональный Telegram бот для поиска событий поблизости и знакомств по интересам с географической привязкой. Бот включает встроенную систему модерации контента, админ-панель и нейросетевую проверку сообщений.

## 🚀 Основные возможности

### 📍 Геолокационные события
- Создание событий с привязкой к текущей локации
- Автоматический поиск событий в радиусе до 10 км
- Визуальное отображение событий на Яндекс.Картах
- Сортировка событий по расстоянию

### 💝 Система знакомств
- Создание анкет для разных целей:
  - 💑 Поиск второй половинки
  - 👥 Поиск общения
  - 🎮 Поиск напарников для игр
  - 🎨 Общие интересы и хобби
  - 💼 Предложенные услуги
- Система лайков и взаимных матчей
- Личные сообщения между пользователями
- Уведомления о новых событиях

### 🛡️ Модерация контента
- Автоматическая проверка на нецензурную лексику
- Отправка подозрительного контента на ручную модерацию
- Полноценная админ-панель для управления контентом
- Система жалоб на пользователей и события

### 🔔 Уведомления
- Новые лайки и взаимные матчи
- Новые сообщения в чатах
- События поблизости
- Результаты модерации

## ⚙️ Установка и запуск

### 1. Клонирование репозитория

```bash
git clone https://github.com/yourusername/spotchat-bot.git
cd spotchat-bot
```

### 2. Создание виртуального окружения

```bash
python -m venv venv
source venv/bin/activate  # Linux/Mac
venv\Scripts\activate     # Windows
```

### 3. Установка зависимостей

```bash
pip install -r requirements.txt
```

### 4. Настройка переменных окружения

Создайте файл `.env` в корне проекта:

```env
BOT_TOKEN=ваш_токен_от_BotFather
DATABASE_URL=sqlite+aiosqlite:///./telegram_bot.db
ADMIN_ID=ваш_telegram_id
```

### 5. Запуск бота

```bash
python main.py
```

### 6. Запуск админ-панели (отдельный терминал)

```bash
python -m uvicorn app.web.main:app --host 0.0.0.0 --port 8000 --reload
```

### 7. Доступ к админ-панели

Откройте браузер: `http://localhost:8000`

| Роль | Логин | Пароль |
|------|-------|--------|
| Admin | `admin` | `admin123` |

## 🖥️ Админ-панель

Админ-панель предоставляет следующие возможности:

### Дашборд
- Общая статистика (пользователи, события, анкеты, жалобы)
- Быстрый доступ к разделам модерации

### Модерация событий
- Просмотр всех событий на модерации
- Одобрение/отклонение с указанием причины
- Автоматическое уведомление автора

### Модерация анкет
- Просмотр анкет пользователей
- Блокировка/одобрение анкет
- Фильтрация по целям поиска

### Управление пользователями
- Список всех пользователей
- Назначение ролей (user/moderator/admin)
- Блокировка/разблокировка

### Система жалоб
- Просмотр жалоб от пользователей
- Обработка с указанием решения
- Уведомление автора жалобы

### Статистика
- Графики активности
- Распределение по статусам
- Ключевые метрики

## 🔌 API эндпоинты

| Метод | Эндпоинт | Описание |
|-------|----------|----------|
| GET | `/` | Страница входа |
| POST | `/api/login` | Аутентификация |
| GET | `/dashboard` | Дашборд |
| GET | `/events/moderation` | События на модерации |
| POST | `/api/events/{id}/approve` | Одобрить событие |
| POST | `/api/events/{id}/reject` | Отклонить событие |
| GET | `/profiles/moderation` | Анкеты на модерации |
| POST | `/api/profiles/{id}/approve` | Одобрить анкету |
| POST | `/api/profiles/{id}/reject` | Отклонить анкету |
| GET | `/users` | Список пользователей |
| GET | `/complaints` | Список жалоб |
| GET | `/statistics` | Статистика |
| GET | `/api/events` | API список событий |
| GET | `/api/events/pending` | API события на модерации |
| GET | `/logout` | Выход |

## 🗄️ Структура базы данных

### Основные таблицы

| Таблица | Описание |
|---------|----------|
| `users` | Пользователи (профиль, роль, статус) |
| `user_locations` | История геолокаций |
| `events` | События (статус модерации, координаты) |
| `user_profiles_by_goal` | Анкеты по целям поиска |
| `user_search_goals` | Активные цели поиска |
| `user_likes` | Лайки между пользователями |
| `chat_messages` | Личные сообщения |
| `user_chats` | Чаты между пользователями |
| `notifications` | Уведомления |
| `complaints` | Жалобы |
| `user_blocks` | Блокировки |

### Модерация
- `events.status` — pending / published / rejected
- `user_profiles_by_goal.moderation_status` — pending / published / rejected
- `user_profiles_by_goal.moderation_reason` — причина отклонения
