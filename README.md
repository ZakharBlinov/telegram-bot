# SpotChat — Telegram бот для поиска событий и знакомств

SpotChat — это многофункциональный Telegram бот для поиска событий поблизости и знакомств по интересам с географической привязкой. Бот включает встроенную систему модерации контента, админ-панель и автоматическую проверку сообщений.

## Основные возможности

**Геолокационные события:** создание событий с привязкой к текущей локации, автоматический поиск событий в радиусе до 10 км, визуальное отображение событий на Яндекс.Картах, сортировка по расстоянию.

**Система знакомств:** создание анкет для разных целей (поиск второй половинки, поиск общения, поиск напарников для игр, общие интересы и хобби, предложенные услуги), система лайков и взаимных матчей, личные сообщения между пользователями, уведомления о новых событиях.

**Модерация контента:** автоматическая проверка на нецензурную лексику, отправка подозрительного контента на ручную модерацию, полноценная админ-панель для управления контентом, система жалоб на пользователей и события.

**Уведомления:** новые лайки и взаимные матчи, новые сообщения в чатах, события поблизости, результаты модерации.

## Установка и запуск

1. Клонирование репозитория: `git clone https://github.com/yourusername/spotchat-bot.git` и `cd spotchat-bot`
2. Создание виртуального окружения: `python -m venv venv`, затем `source venv/bin/activate` (Linux/Mac) или `venv\Scripts\activate` (Windows)
3. Установка зависимостей: `pip install -r requirements.txt`
4. Настройка переменных окружения: создайте файл `.env` с переменными `BOT_TOKEN`, `DATABASE_URL` и `ADMIN_ID`
5. Запуск бота: `python main.py`
6. Запуск админ-панели (в отдельном терминале): `python -m uvicorn app.web.main:app --host 0.0.0.0 --port 8000 --reload`
7. Доступ к админ-панели: откройте браузер по адресу `http://localhost:8000`, логин `admin`, пароль `admin123`

## Админ-панель

**Дашборд:** общая статистика (пользователи, события, анкеты, жалобы), быстрый доступ к разделам модерации. **Модерация событий:** просмотр событий на модерации, одобрение или отклонение с указанием причины, автоматическое уведомление автора. **Модерация анкет:** просмотр анкет пользователей, блокировка или одобрение, фильтрация по целям поиска. **Управление пользователями:** список всех пользователей, назначение ролей (user/moderator/admin), блокировка и разблокировка. **Система жалоб:** просмотр жалоб от пользователей, обработка с указанием решения, уведомление автора жалобы. **Статистика:** графики активности, распределение по статусам, ключевые метрики.

## API эндпоинты

`GET /` — страница входа, `POST /api/login` — аутентификация, `GET /dashboard` — дашборд, `GET /events/moderation` — события на модерации, `POST /api/events/{id}/approve` — одобрить событие, `POST /api/events/{id}/reject` — отклонить событие, `GET /profiles/moderation` — анкеты на модерации, `POST /api/profiles/{id}/approve` — одобрить анкету, `POST /api/profiles/{id}/reject` — отклонить анкету, `GET /users` — список пользователей, `GET /complaints` — список жалоб, `GET /statistics` — статистика, `GET /logout` — выход.
